# מעקב רודימנטים – גרסה 2.1

אפליקציית תרגול ומעקב לרודימנטים על פד: שגרה יומית עם מטרונום, מעבר אוטומטי בין שלבים ודירוג אחרי כל שלב, מדידה שבועית מודרכת, גרפי התקדמות, ספריית תרגילים וסנכרון דו-כיווני בין מכשירים (Cloudflare D1). הממשק כולו בעברית, מימין לשמאל, בערכת הצבעים "Warm Sand" (בהיר וכהה).

## מה יש באפליקציה
- **בית** – התוכנית של היום, רצף ימים, פס שבועי, סיכום יעדים, וכפתור גדול "התחל תרגול של היום".
- **תרגול** – השגרה רצה שלב אחרי שלב: ספירה של 4, מטרונום וטיימר, צליל קצר בסוף, דירוג (נקי / סביר / נשבר), 15 שניות מנוחה עם תצוגה של השלב הבא, ואז השלב הבא מתחיל לבד. יש גם **מצב מיקוד** במסך מלא.
- **מדידה שבועית** – בוחרים תרגיל, הטמפו עולה אוטומטית (ברירת מחדל: ‎+5 כל 30 שניות), לוחצים פעם אחת כשנהיה קשה ופעם שנייה כשזה נשבר. נשמר כמקסימום נקי. אפשר להריץ את כל הרשימה השבועית ברצף.
- **התקדמות** – גרף לכל תת-תרגיל, יעדים, והשוואת ימין/שמאל רק בין מדידות באותה חלוקה.
- **ספרייה** – כל הרודימנטים, הרולים והמבחנים, עם סטיקינג והסבר קצר. אפשר להוסיף ולערוך תרגילים ותתי-תרגילים משלך.
- **הגדרות** – סנכרון בין מכשירים, ערכת צבעים, ייבוא וייצוא, עורך השגרה, רשימת המדידה השבועית.

האפליקציה לא משנה קצבים בעצמה. הדירוג נרשם כ"טמפו עבודה" ולא נוגע במקסימום הנקי.

### חדש בגרסה 2.1 (במסך התרגול)
- **הצעה להעלות טמפו** – אחרי 3 דירוגים "נקי" ברצף באותו BPM לאותו תרגיל, מופיעה הצעה להעלות את היעד של השלב ב-4. לחיצה אחת מאשרת, "לא עכשיו" מסתיר את ההצעה לטמפו הזה. "סביר" ו"נשבר" נחשבים "לא נקי" ושוברים את הרצף.
- **הקלטה קצרה** – כפתור הקלטה מהמיקרופון, עד 30 שניות עם ספירה לאחור, ואז "השמע" כדי לשמוע את עצמך. נשמרת רק ההקלטה האחרונה, בזיכרון בלבד: לא נשמרת, לא מסונכרנת ונמחקת ברענון.
- **מטרונום עם הפסקות** – מתג "מטרונום עם הפסקות": מספר תיבות עם קליק ומספר תיבות בשקט (ברירת מחדל: 3 ו-1). בתיבות השקט הנקודות ממשיכות לפעום בעמעום. כבוי כברירת מחדל, נשמר עם הגדרות המטרונום, ופועל רק בשגרה (לא במדידה).

### דירוג בדיעבד
שכחת ללחוץ נקי / סביר / נשבר במנוחה? השלב בכל זאת נשמר כטמפו עבודה "ללא דירוג", ואפשר לדרג אותו אחר כך:
- **בסיכום שבסוף השגרה** – שלושה כפתורים ליד כל שלב. לחיצה על הדירוג הנוכחי מבטלת אותו.
- **בהתקדמות ← היסטוריה** – לחיצה על הדירוג (או על "ללא דירוג") של כל טמפו עבודה, בכל תאריך. אפשר גם לשנות או להחזיר ל"ללא דירוג".
- **בבית** – כשיש שלבים מהשגרה בלי דירוג מ-7 הימים האחרונים מופיעה שורה קטנה, ו"לדרג עכשיו" פותח חלון עם כולם.

הדירוג נשמר על אותה רשומה ומסתנכרן לשאר המכשירים. המקסימום הנקי לא מושפע.

### מתי הטמפו עולה
אף פעם לא לבד. אחרי **3 דירוגי "נקי" ברצף** לאותו תרגיל באותו BPM, מופיעה במנוחה הצעה להעלות את היעד של השלב ב-4 – ורק לחיצה שלך מאשרת. "סביר" או "נשבר" שוברים את הרצף; שלב בלי דירוג לא נספר ולא שובר. דירוג בדיעבד נספר כמו דירוג רגיל, כך שההצעה תופיע בתרגול הבא אם הרצף הגיע ל-3.

## פתיחה מקומית
אין צורך בהתקנה או בשרת. פותחים את הקובץ `index.html` בדפדפן (Chrome / Edge / Safari), בלחיצה כפולה.

הנתונים נשמרים בדפדפן (localStorage). אם השתמשת בגרסה 1 באותו דפדפן ומאותה תיקייה, הנתונים מועברים אוטומטית בפתיחה הראשונה, ונשמר עותק גיבוי של נתוני גרסה 1. אחרת: **הגדרות ← ייבוא קובץ** עם קובץ ייצוא מגרסה 1 או 2.

## הפעלה ב-GitHub Pages
1. ב-GitHub: **Settings ← Pages**.
2. תחת **Build and deployment** בחר **Deploy from a branch**.
3. בחר את הענף `main` (אחרי המיזוג) ואת התיקייה `/ (root)`, ולחץ **Save**.
4. אחרי דקה-שתיים האתר זמין בכתובת:
   https://deadpaul134.github.io/-rudiments-tracker/

שים לב: הנתונים בדפדפן נשמרים לפי כתובת. מה שנשמר בפתיחה מקובץ מקומי לא יופיע אוטומטית בכתובת של GitHub Pages. כדי להעביר: **ייצוא נתונים** במקום אחד ו**ייבוא קובץ** במקום השני (או פשוט סנכרון בין מכשירים – ראה למטה).

הערה: אם המאגר פרטי, GitHub Pages דורש חשבון בתשלום, או שצריך להפוך את המאגר לציבורי.

## סנכרון בין מכשירים (Cloudflare)
הסנכרון מחליף את גוגל שיטס. האפליקציה והסנכרון יושבים יחד ב-Cloudflare Pages: האתר הסטטי, ופונקציה אחת בכתובת `/api/sync` ששומרת את הנתונים במסד D1.

מה עובר בין המכשירים: רשומות (מקסימום נקי וטמפו עבודה עם דירוג), יומן התרגולים, ימי תרגול, השגרה, תרגילים ותתי-תרגילים שהוספת ורשימת המדידה השבועית. ערכת הצבעים, המטרונום ושאר העדפות התצוגה נשארים נפרדים בכל מכשיר.

איך זה עובד:
- הסנכרון רץ בפתיחה, כשחוזרים לחלון, אחרי כל רשומה (תוך שניה-שתיים), ובכפתור **סנכרן עכשיו**.
- בלי אינטרנט הכל נשמר במכשיר ונשלח כשהחיבור חוזר.
- כשאותה רשומה השתנתה בשני מכשירים – השינוי האחרון נשאר. המקסימום הנקי אף פעם לא יורד בגלל סנכרון.
- מחיקה מפורשת של רשומה מוחקת אותה בכל המכשירים. שום דבר אחר לא נמחק.
- **ייצוא לקובץ** בכרטיס הסנכרון מוריד קובץ גיבוי מלא (אותו קובץ כמו "ייצוא נתונים").

### הקמה (פעם אחת)
הפקודות המדויקות, לפי הסדר, נמצאות בקובץ `SYNC_REPORT.md`. בקצרה: יוצרים מסד D1, מדביקים את המזהה שלו ב-`wrangler.toml`, מריצים את קובץ יצירת הטבלה, שומרים את קוד הגישה כסוד `SYNC_CODE`, ומפרסמים.

### חיבור מכשיר
פותחים את האתר בכתובת של Cloudflare Pages ← **הגדרות ← סנכרון בין מכשירים** ← מקלידים את קוד הגישה ← **שמור**. הקוד נשמר רק בדפדפן של אותו מכשיר ולא בקוד.

כשפותחים את `index.html` כקובץ מקומי מופיע גם שדה **כתובת השרת** – מדביקים בו את כתובת האתר ב-Cloudflare.

## הרצת הבדיקות
צריך Node.js 18 ומעלה.

```bash
npm install
npx playwright install chromium
npm test
```

הבדיקות (Playwright) מכסות: העברת נתונים מגרסה 1 וייבוא קבצים, מעבר אוטומטי בין שלבים ורישום דירוגים, קיצורי מקלדת, מדידה שבועית, החלפת ערכת צבעים, סנכרון דו-כיווני מול הפונקציה האמיתית עם מסד SQLite מקומי במקום D1 (מיזוג שני מכשירים, מחיקות, מקסימום נקי, קוד שגוי, עבודה בלי חיבור), ומגרסה 2.1 גם הצעת ‎+4 BPM, הקלטה (עם מיקרופון מדומה) ומטרונום עם הפסקות.

צילומי מסך של כל המסכים (בהיר וכהה, מחשב וטאבלט) נוצרים מחדש עם:

```bash
npm run screenshots
```

והם נשמרים בתיקייה `screenshots/`.
